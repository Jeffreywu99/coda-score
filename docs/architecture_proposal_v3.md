# Coda-Score 架构升级方案 v3.0
**从纯视觉扩散到“符号-编译-视觉”混合生成管线**

---

## 1. 旧方案回顾与痛点分析

### 1.1 旧方案架构 (纯视觉生成模式)
- **核心逻辑**：将现代乐谱视为纯粹的“视觉图形”（Visual Grammar），直接利用 SDXL 加上针对 Boulez 等现代乐谱训练的 LoRA 模型，通过 `txt2img` 或基础的 `img2img` 模式进行端到端的图像生成。
- **预期目标**：输入文本提示，直接输出一张具有现代音乐排版风格的乐谱。

### 1.2 核心痛点与幻觉现象
- **音乐逻辑丧失**：扩散模型的本质是学习像素的概率分布，而非乐理法则。模型学习到了现代乐谱的“材质”和“纹理”（如密集的音符、倾斜的连音线），但完全无法维持节拍、音高对位、声部连贯性等底层数学逻辑。结果生成了**“看起来像乐谱的无意义图形”**。
- **降维妥协无效**：曾尝试“单行钢琴谱生成后拼接”的降维方案，但由于各行之间缺乏和声与动机的上下文关联，且视觉上无法完美对齐，拼接结果依然是逻辑断裂的。

---

## 2. 新方案提出：极简混合架构 (Hybrid Pipeline)

为了在**“绝对严密的音乐逻辑”**与**“现代派的视觉美感”**之间取得平衡，系统架构必须将逻辑生成与视觉渲染解耦。由于 MusicXML 过于臃肿且无法表达现代图形记谱，新方案采用最直接高效的**“LLM直出 LilyPond (逻辑与图形编译) + ControlNet (视觉风格化)”**两级流线。

### 2.1 架构分层详解

#### 第一层：逻辑与编译层 (Logic & Compile Engine)
- **工具**：大语言模型 (LLM) + LilyPond 编译引擎
- **任务**：
  1. LLM 直接根据用户需求生成 **LilyPond 代码**。这不仅能保证音符逻辑完美（Token消耗小），还能在代码中直接调用我们预设的“现代图形记谱宏”（如 `\markup { \path }` 绘制特殊的墨迹、连音、音簇图形）。
  2. LilyPond 引擎将代码编译，渲染出一张**高精度、黑白分明、绝对逻辑正确且带有基础现代图形**的骨架乐谱图 (PNG)。

#### 第二层：视觉美学层 (Visual Aesthetic Engine)
- **工具**：Stable Diffusion (SDXL) + ControlNet (Canny / Lineart) + Boulez LoRA
- **任务**：将第一层生成的“死板”骨架黑白图作为 ControlNet 的底图输入。由于 ControlNet 锁死了所有音符和线条的像素位置（空间锚定），扩散模型无法改变音乐逻辑。此时，Boulez LoRA 发挥作用，将干瘪的线条重绘为具有手绘笔触、墨迹晕染、纸张年代感的现代主义艺术品。

## 3. 新旧方案对比 (Pipeline Comparison)

| 比较维度 | 旧方案 (纯扩散模型 txt2img) | 新方案 (LLM -> LilyPond -> ControlNet) |
| :--- | :--- | :--- |
| **基础逻辑约束** | 无。依赖扩散模型随机掷骰子生成像素。 | **绝对严谨**。由 LilyPond 语法强约束。 |
| **乐理正确性** | 极低（几乎为0，大量视觉幻觉）。 | **极高**（完全可演奏、可视奏）。 |
| **现代图形注入** | 靠模型随机生成，不可控且容易破坏五线谱结构。 | 靠 LilyPond 矢量绘图指令精确注入，**高度可控**。 |
| **Token 消耗与速度**| N/A | **极低**（直接生成 LilyPond 文本，跳过冗长的 XML）。 |
| **视觉美学 (Boulez风格)** | 优秀（但因逻辑崩塌导致整体如同乱码）。 | **完美**（在严密骨架上赋予艺术材质，形神兼备）。 |

## 4. 实施可行性与下一步开发计划

此架构从工程和学术角度均具备高度可行性，直接抛弃了繁杂的中转格式，是真正面向“现代艺术乐谱”的最优解。

### 阶段一：打通逻辑到基础图像的链路
- [ ] 建立**现代图形指令库 (Snippet Library)**：在 LilyPond 中手动编写 3-5 个常用的现代图形记谱宏命令（如音簇、滑音矢量线）。
- [ ] 设计 LLM Prompt：使用 Few-shot 方式，让大模型学习这几个宏命令，使其能够稳定输出带有特殊图形指令的 LilyPond 代码。
- [ ] 跑通自动化脚本：利用 LilyPond 批量将 LLM 输出的代码渲染为黑白五线谱图像 (PNG)。

### 阶段二：打通基础图像到视觉美学的链路
- [ ] 调试 ControlNet 参数：使用 `Canny` 或 `Lineart` 预处理器，将阶段一渲染的黑白 PNG 作为约束条件。
- [ ] 结合目前的 `boulez.safetensors` LoRA 进行实验，调节重绘幅度 (Denoising Strength，建议在 0.4 - 0.7 之间测试)，确保在不破坏音符位置的前提下，最大化 Boulez 的视觉风格。
