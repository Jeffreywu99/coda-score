# LilyPond 核心基础语法字典 (Core Syntax)

**用途声明**：
本文件是所有乐谱生成的最底层骨架规则。在生成任何基于 LilyPond 的代码时，必须优先满足本文件定义的文件结构与基础排版逻辑，然后再叠加特定现代音乐风格的规则。

## 1. 全局文件结构 (Global Structure)
生成的 LilyPond 代码必须遵循严格的结构分层。**绝对禁止**将音符直接暴露在顶层，必须包裹在 `\score`, `\new Staff`, `\new Voice` 结构中。

**标准骨架模板：**
```lilypond
\version "2.24.0"

% 1. 定义音乐内容（强烈建议使用变量分离逻辑）
musicContent = \relative c'' {
  % 音乐代码写在这里
  c4 d e f |
}

% 2. 乐谱结构组装
\score {
  \new Staff {
    \new Voice {
      \musicContent
    }
  }
  
  % 3. 全局排版引擎控制
  \layout {
    % 所有特定风格的 \context 覆盖必须写在 \layout 块中
    \context {
      \Score
      proportionalNotationDuration = #(ly:make-moment 1/16)
    }
  }
}
```

## 2. 基础语法红线 (Syntax Red Lines)
为了确保 100% 编译成功，以下规则不可违背：

1. **大小写严格敏感**：音高必须为小写字母 `c d e f g a b`。命令首字母多数为小写（如 `\relative`），但 Context 名称首字母必须大写（如 `\Staff`, `\Voice`）。
2. **符号与空格**：所有的花括号 `{ }`、书名号 `<< >>` 与周围的字符必须有空格隔开。例：正确 `\relative { c4 }`，错误 `\relative{c4}`。
3. **连音符与连奏**：
   - 延音线 (Tie, 连接相同音高)：使用 `~`，必须紧跟在第一个音符后面，没有空格，例：`c4~ c8`。
   - 连奏线 (Slur, 连接不同音高)：使用 `( )`，起始圆括号紧贴第一个音符后，结束圆括号紧贴最后一个音符后，例：`c4( d e f)`。

## 3. 音高与相对模式 (\relative)
在现代音乐生成中，强烈建议使用 `\relative` 或 `\fixed` 模式。
- `\relative c'' { }`：每一个音符的默认八度将自动寻找距离前一个音符**最近**的八度（四度以内）。
- 使用 `'` 升高八度，使用 `,` 降低八度。
- **注意**：在计算相对距离时，LilyPond **完全忽略变音记号**（升降号）。

## 4. 节奏与时值 (Rhythm & Durations)
- 时值数字紧跟在音高后面：`c4` (四分音符), `d8` (八分音符), `e16` (十六分音符)。
- 如果一个音符没有写时值，它将**继承上一个音符的时值**。为了防止大模型生成导致的时值错乱，在新的小节开头或复杂的连音后，**必须显式标明时值**。
- 休止符：使用小写字母 `r` 加上时值，如 `r4`。

## 5. 多声部与和弦 (Polyphony & Chords)
- **和弦**：使用单尖括号 `< >` 包裹音高，时值写在右括号外。例：`<c e g>4`。
- **单行谱多声部**：使用 `<< { ... } \\ { ... } >>` 语法。
```lilypond
\new Staff {
  <<
    { c''4 d'' e'' f'' } \\ % 声部1，符干朝上
    { c'2 g' }              % 声部2，符干朝下
  >>
}
```
