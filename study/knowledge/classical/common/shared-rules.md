## 二、`\relative` 模式详解

### 基本原理

`\relative` 后跟一个参考音，设定第一个音符的八度。之后每个音符的八度由**与前一个音符的距离**自动判定。

### 关键规则

1. **纯四度以内的进行**：自动保持在合理八度，不需要八度标记
   - `\relative c' { c d e f }` → C4 D4 E4 F4（上行级进，自然保持）
   - `\relative c' { c b a g }` → C4 B3 A3 G3（下行级进，自然保持）

2. **超过纯四度的跳进**：需要显式八度标记 `'` 或 `,`
   - `\relative c' { c g }` → C4 G4 还是 C4 G3？**取决于具体音程，建议显式标注**
   - 安全做法：`\relative c' { c g' }` → 明确要 G4+八度

3. **八度标记含义**：
   - `'`（单引号）：比自然八度高一个八度
   - `''`（双引号）：高两个八度
   - `,`（逗号）：低一个八度
   - `,,`（双逗号）：低两个八度

### 常见错误与修正

| 错误 | 后果 | 正确写法 |
|------|------|---------|
| 大提琴用 `\relative c''` | 所有音符高两个八度，跑到上加线 | 用 `\relative c` |
| 低音提琴忘记低八度记谱 | 实际音高比预期高八度 | 低音提琴**记谱比实际音高高八度** |
| 钢琴左手用 `\relative c'` | 音符偏高，跑到右手区域 | 用 `\relative c` |
| 男高音忘记 treble_8 谱号 | 八度关系混乱 | 用 `\clef "treble_8"` + `\relative c'` |
| 在 `\relative` 中混用绝对音高 | 八度跳跃不可预测 | 全程使用 `\relative` 逻辑 |

### 参考起始音速记

| 乐器组 | `\relative` 参考 | 记忆口诀 |
|--------|------------------|---------|
| 高音乐器（小提琴/长笛/女高音） | `c''` | 两个撇号 = 高音 |
| 中音乐器（中提琴/Bb单簧管/女中音） | `c'` | 一个撇号 = 中音 |
| 低音乐器（大提琴/大管/男低音/钢琴左手） | `c` | 无撇号 = 低音 |
| 倍低音乐器（低音提琴/低音大管） | `c` | 无撇号 + 记谱高八度 |
| 极高乐器（短笛/钟琴） | `c'''` | 三个撇号 = 极高 |

## 三、通用音乐规则

### 3.1 通用禁止项（适用于所有调性写作）

| 禁止项 | 定义 | 适用范围 |
|--------|------|---------|
| **平行五度** | 任意两个声部之间，连续两个纯五度同向进行 | 所有调性写作 |
| **平行八度** | 任意两个声部之间，连续两个纯八度同向进行 | 所有调性写作 |
| **反行五度** | 纯五度通过反向运动到另一个纯五度 | 严格对位 |
| **声部交错** | 高音部低于中音部，或中音部低于次中音部 | 所有多声部写作 |
| **声部超越** | 一个声部越过相邻声部的前一个音的位置 | 所有多声部写作 |

### 3.2 声部进行优先级

| 优先级 | 运动类型 | 说明 |
|--------|---------|------|
| 1（最佳） | 反向运动 | 两声部向相反方向 |
| 2 | 斜向运动 | 一声部保持，另一声部运动 |
| 3 | 同向运动 | 同方向但音程不同 |
| 4（最差） | 平行运动 | 仅允许平行三度和平行六度（最多连续 3 个） |

### 3.3 隐伏五度/八度

当**外声部**（最高+最低）**同向运动**进入纯五度或纯八度，且**高音部跳进**时：
- 尽量避免（削弱声部独立性）
- 若高音部为级进则可接受

### 3.4 旋律通用规则

| 规则 | 说明 |
|------|------|
| 级进优先 | 音阶式进行是最自然的 |
| 共同音保持 | 和弦切换时，共同音尽量在同一声部保持 |
| 跳进后反向 | 跳进之后应反向级进 |
| 最大跳进 | 上三声部 ≤ 纯五度（低音可更自由） |
| 八度跳进后必须反向 | |
| 禁止旋律音程 | 增二度、减五度（旋律中）、增四度（旋律中） |

### 3.5 和弦重复规则

| 和弦类型 | 重复规则 |
|---------|---------|
| 原位三和弦 | 优先重复根音 |
| 六和弦 | 重复根音或三音 |
| 四六和弦 | **始终重复低音** |
| 七和弦 | 四个音全部出现；省略五音时重复根音 |
| 减三和弦 | 重复三音（不可重复根音） |
| **导音** | **绝不重复** |
| **和弦七音** | **绝不重复** |

### 3.6 倾向音解决

| 倾向音 | 解决方向 |
|--------|---------|
| 导音（第7级） | 上行级进到主音 |
| 和弦七音 | 下行级进 |
| 升号变化音 | 上行解决 |
| 降号变化音 | 下行解决 |
| 三全音中的 7 | 上行到 1 |
| 三全音中的 4 | 下行到 3 |

### 3.7 声部间距

| 声部对 | 最大间距 |
|--------|---------|
| 上三声部相邻声部（S-A, A-T） | ≤ 八度 |
| 低音与次中音（T-B） | 无限制 |

### 3.8 终止式

| 终止式 | 进行 | 条件 |
|--------|------|------|
| PAC（完满正格） | V(7) → I | 均原位，高音结束于主音 |
| IAC（不完满正格） | V(7) → I | 高音非主音或有转位 |
| HC（半终止） | ? → V | 停在属和弦 |
| DC（阻碍终止） | V → vi | 期待 I 被替代 |
| PC（变格终止） | IV → I | "阿门"终止 |

### 3.9 节奏独立性（多声部写作的核心要求）

**多声部音乐中，每个声部必须拥有不同的节奏型。禁止所有声部使用完全相同的音符时值。**

| 原则 | 说明 |
|------|------|
| **节奏互补** | 一个声部用长音时，另一个声部应该活跃；反之亦然 |
| **角色分工** | 旋律声部最活跃（八分音符），内声部中等（附点/休止），低声部最稳定（二分音符） |
| **禁止同节奏** | 四个声部全部写 `c4 d e f` 是错误的——这是大齐奏，不是和声 |

#### SATB 节奏分配参考

| 声部 | 节奏特征 | 典型写法 |
|------|---------|---------|
| Soprano（旋律） | 最活跃 | 四分+八分音符混合：`e4 d8 e8 c4. b8` |
| Alto（和声填充） | 较稳定 | 二分音符+附点：`g2. a4` 或 `g4 f4 e2` |
| Tenor（和声填充） | 中等，带休止 | 附点节奏+休止：`c4. b8 c4 r4` |
| Bass（基础） | 最稳定 | 二分音符为主：`c2 f2` 或 `g2 e2` |

#### 钢琴节奏分配参考

| 手 | 节奏特征 | 典型写法 |
|----|---------|---------|
| 右手（旋律） | 抒情，附点节奏 | `c4. d8 e4 g4` |
| 左手（伴奏） | 持续流动 | Alberti 低音：`c8 g' e g c g e g` |

#### 弦乐四重奏节奏分配参考

| 声部 | 节奏特征 |
|------|---------|
| Violin I（旋律） | 最活跃，八分音符 |
| Violin II（对旋律） | 中等活跃，与 Vln I 互补 |
| Viola（和声） | 附点节奏 + 休止 |
| Cello（基础） | 二分音符，稳定 |

#### 示例：节奏独立的 4 小节 SATB

```lilypond
\version "2.24.0"
\score {
  \new ChoirStaff <<
    \new Staff \relative c'' {
      \clef treble
      \time 4/4
      % Soprano：八分音符旋律（最活跃）
      e4 d8 e8 c4. b8 | a4 b4 c4 d4 | e2 d4 c4 | c2. r4
    }
    \new Staff \relative c' {
      \clef treble
      \time 4/4
      % Alto：二分音符长音（最稳定）
      g2. a4 | g4 f4 e2 | g2 f4 e4 | e2. r4
    }
    \new Staff \relative c' {
      \clef "treble_8"
      \time 4/4
      % Tenor：附点节奏 + 休止（中等）
      c4. b8 c4 r4 | c2 b4. a8 | c2 b4 a4 | g2. r4
    }
    \new Staff \relative c {
      \clef bass
      \time 4/4
      % Bass：二分音符基础（稳定）
      c2 f2 | g2 e2 | c2 g2 | c2. r4
    }
  >>
  \layout { }
}
```

注意四个声部的节奏型完全不同：Soprano 有八分音符，Alto 是二分音符，Tenor 有附点和休止，Bass 是二分音符。

## 四、LilyPond 通用语法规范

### 4.1 文件结构（必须包含）

```lilypond
\version "2.24.0"
\score {
  % 音乐内容
  \layout { }
}
```

### 4.2 音符输入

| 语法 | 含义 |
|------|------|
| `c d e f g a b` | 自然音 |
| `cis` / `des` | 升C / 降D |
| `c4` `c8` `c16` | 四分/八分/十六分音符 |
| `c4.` | 附点四分音符 |
| `c2~ c4` | 连音线 |
| `r4` | 四分休止符 |
| `R1` | 全小节休止 |

### 4.3 和弦与多声部

| 语法 | 含义 |
|------|------|
| `<c e g>4` | C大三和弦（四分音符） |
| `<< { 高声部 } \\ { 低声部 } >>` | 同一谱表上的两个声部 |
| `\new Staff << \new Voice ... >>` | 多声部在独立谱表上 |

### 4.4 表情与演奏法

| 语法 | 含义 |
|------|------|
| `c4\p` `c4\f` `c4\ff` | 力度 |
| `c4\<` `c4\>` `c4\!` | 渐强/渐弱/终止 |
| `c4->` | 重音 |
| `c4-.` | 跳音 |
| `c4--` | 保持音 |
| `c4-^` | 强音 |
| `c4(_)` | 圆滑线 |
| `c4[^]` | 连音线 |

### 4.5 反复结构

```lilypond
\repeat volta 2 {
  % 反复段
}
\alternative {
  { % 第一结尾 }
  { % 第二结尾 }
}
```

### 4.6 谱号选择

| 乐器/声部 | 谱号 |
|-----------|------|
| 小提琴、长笛、双簧管、Bb单簧管、圆号、小号、女高音、女中音 | `\clef treble` |
| 中提琴 | `\clef alto` |
| 大提琴、大管、长号、大号、男低音、钢琴左手 | `\clef bass` |
| 男高音 | `\clef "treble_8"` |

### 4.7 移调乐器记谱

| 乐器 | 移调方向 | 记谱方法 |
|------|---------|---------|
| Bb单簧管/Bb小号 | 记谱比实际音高**高大二度** | 实际 Bb → 记谱 C |
| F圆号 | 记谱比实际音高**高纯五度** | 实际 F → 记谱 C |
| 英国管 | 记谱比实际音高**高纯五度** | 实际 F → 记谱 C |
| 低音提琴 | 记谱比实际音高**高八度** | 实际 C2 → 记谱 C3 |

## 五、模板 — 知识上下文对应表

检索系统根据用户选择的模板（或从用户描述推断的场景），只注入匹配的知识文件：

| 模板 ID / 场景 | 注入的知识文件 | 不注入的文件 |
|----------------|--------------|-------------|
| satb-choir, satb-piano | shared-rules + aldwell + fux + caplin | adler（管弦乐段）、rimsky |
| string-quartet | shared-rules + fux + caplin + adler（弦乐段） | aldwell（SATB音域）、kostka |
| piano-solo, piano-voice | shared-rules + aldwell + caplin + green | adler、rimsky、fux |
| duet, woodwind-trio | shared-rules + fux + adler（木管段） | aldwell（SATB音域）、caplin |
| brass-quintet | shared-rules + adler（铜管段）+ caplin | aldwell（SATB音域）、fux |
| twelve-tone-row/matrix | shared-rules + schoenberg | aldwell、kostka、adler |
| microtonal, cluster, proportional, graphic-staff | shared-rules + schoenberg + adler | aldwell、kostka、caplin |
| solo-melody, solo-bass | shared-rules + caplin + green | aldwell、adler |
| chord-progression, pitch-class-chord | shared-rules + aldwell + kostka | adler、rimsky |
| 无模板 / 自由创作 | shared-rules + 根据用户描述关键词选择 1-2 个最相关文件 | — |

**关键原则**：
1. `shared-rules.md` 始终注入（所有场景共享）
2. 音域数据只从 `shared-rules.md` 获取，其他文件不定义音域
3. 和声类文件（aldwell/kostka）只在需要和声写作时注入，避免与配器音域冲突
4. 每次注入不超过 3 个知识文件（含 shared-rules），保持 prompt 精简

## 六、AI 生成约束总结

生成任何 LilyPond 代码时，必须：

1. **查音域**：每个声部/乐器的音符必须在上表范围内，优先在最佳音区
2. **选对 `\relative`**：根据上表的参考起始音设置
3. **遵守通用禁止项**：无平行五度/八度、无声部交错/超越
4. **倾向音正确解决**：导音上行、七音下行
5. **声部间距合理**：上三声部相邻 ≤ 八度
6. **文件结构完整**：`\version` + `\score` + `\layout`
7. **谱号正确**：每个乐器/声部使用对应谱号
8. **移调乐器正确处理**：Bb 乐器记谱高大二度，F 乐器记谱高纯五度
