# 圣咏织体（Chorale）— 巴赫风格四部和声

圣咏（Chorale）是路德宗赞美诗的传统形式，经巴赫（J.S. Bach）发展为调性和声的典范。其核心特征：**主调织体（homophonic）中蕴含声部独立性**。

> 音域、谱号、`\relative` 参考及通用禁止项 → 见 shared-rules.md

---

## 一、圣咏的核心特征

| 特征 | 说明 |
|------|------|
| **主调织体** | 四个声部（SATB）以和弦为基础，纵向对齐 |
| **节奏独立** | 每个声部拥有不同的节奏型，不是"齐奏" |
| **音节式配词** | 一个音节对应一个音符（syllabic），少用花唱 |
| **乐句结构** | 4 小节为一句，句末用延长记号（fermata）分隔 |
| **力度克制** | mp–mf 范围，庄重温暖，不追求戏剧性对比 |

### 声部节奏分工（关键！）

圣咏最容易犯的错误是四个声部节奏完全相同。正确做法：

| 声部 | 角色 | 节奏特征 | 典型时值 |
|------|------|---------|---------|
| Soprano | 旋律 | **最活跃** | 四分音符 + 八分音符装饰 |
| Alto | 和声填充 | 较稳定 | 附点二分音符 + 四分音符 |
| Tenor | 内声部 | 中等，带休止 | 附点四分音符 + 八分音符 + 休止 |
| Bass | 基础 | **最稳定** | 二分音符为主 |

## 二、完整示例 — G 大调圣咏（16 小节）

**调性**：G 大调（一个升号 F#）
**拍号**：4/4
**结构**：4 个乐句 × 4 小节，每句以 fermata 结束
**和声进行**：

| 乐句 | 进行 | 终止 |
|------|------|------|
| 第一句（1-4） | I - IV - V - I | 正格终止（IAC） |
| 第二句（5-8） | I - vi - IV - V | 半终止（HC） |
| 第三句（9-12） | I - IV - I - V | 半终止（HC） |
| 第四句（13-16） | I - IV - V - I | 完满正格终止（PAC） |

```lilypond
\version "2.24.0"

\score {
  \new ChoirStaff <<

    % ═══════════════════════════════════════════════════
    % 女高音 Soprano — 旋律声部（最活跃）
    % 音域参考：C4–A5，最佳 E4–G5 → 见 shared-rules.md
    % ═══════════════════════════════════════════════════
    \new Staff \relative c'' {
      \clef treble
      \key g \major
      \time 4/4
      \tempo "Andante moderato" 4 = 80

      % === 第一乐句（1-4小节）：G(I) - C(IV) - D(V) - G(I) ===
      % 旋律从五音(D5)开始，八分音符装饰增加流动性
      \mp
      d4 e8 d8 b4 g4 |        % 1: D5-E5-D5-B4-G4，I级上行后下行
      c4. d8 e4 d4 |           % 2: C5-D5-E5-D5，IV级区域，附点节奏
      d4 cis8 b8 a4 fis4 |     % 3: D5-C#5-B4-A4-F#4，经过导音(cis)下行
      g2.\fermata r4 |          % 4: G4 延长，I级终止（IAC：三音在低音）

      % === 第二乐句（5-8小节）：G(I) - Em(vi) - C(IV) - D(V) ===
      % 旋律在中音区起伏，为半终止做准备
      b4 d4 e4 d4 |            % 5: B4-D5-E5-D5，上行到vi级区域
      b4 a4 g4 fis4 |          % 6: B4-A4-G4-F#4，级进下行
      e4 g4 a4 b4 |            % 7: E4-G4-A4-B4，重新上行蓄力
      a2.\fermata r4 |          % 8: A4 延长，V级半终止（A=V的五音）

      % === 第三乐句（9-12小节）：G(I) - C(IV) - G(I) - D(V) ===
      % 旋律到达高音G5后回落
      \mf
      d4 e4 g4 e4 |            % 9: D5-E5-G5-E5，跳进到高音区
      e4 d4 c4 b4 |            % 10: E5-D5-C5-B4，平稳级进下行
      d4 b4 d8 e8 d4 |         % 11: D5-B4-D5-E5-D5，八分音符装饰
      a2.\fermata r4 |          % 12: A4 延长，V级半终止

      % === 第四乐句（13-16小节）：G(I) - C(IV) - D(V) - G(I) ===
      % 最终乐句：渐强推向完满终止
      d4 e4 g4 d4 |            % 13: D5-E5-G5-D5，再次触及高音
      e4 d4 c4 b4 |            % 14: E5-D5-C5-B4，下行经过IV级
      \\<
      d4 a4 d4 cis4 |          % 15: D5-A4-D5-C#5，V级，导音准备解决
      g2.\fermata r4 \! |      % 16: G5 延长，PAC！主音在高音
    }

    % ═══════════════════════════════════════════════════
    % 女中音 Alto — 和声填充（较稳定）
    % 注意：二分音符和附点节奏为主，与 Soprano 的八分音符形成互补
    % ═══════════════════════════════════════════════════
    \new Staff \relative c' {
      \clef treble
      \key g \major
      \time 4/4

      % === 第一乐句 ===
      % Alto 用长音支撑和声，附点二分音符制造"呼吸感"
      b2. d4 |                 % 1: B3(附点二分)-D4(四分)，I级三音→五音
      c2 e4 c4 |               % 2: C4-E4-C4，IV级根音→三音→根音
      d1 |                     % 3: D4 全音符持续（V级五音保持）
      b2.\fermata r4 |          % 4: B3 延长（I级三音）

      % === 第二乐句 ===
      b2 d4 b4 |               % 5: B3-D4-B3，I级三音起伏
      d2. b4 |                 % 6: D4(附点二分)-B3，vi级五音→三音
      e2 c4 e4 |               % 7: E4-C4-E4，IV级三音→根音→三音
      fis2.\fermata r4 |        % 8: F#4 延长（V级三音=导音）

      % === 第三乐句 ===
      g2. e4 |                 % 9: G4(附点二分)-E4，I级根音→三音(高八度)
      e2 c4 e4 |               % 10: E4-C4-E4，IV级
      d2. b4 |                 % 11: D4-B3，I级五音→三音
      fis2.\fermata r4 |        % 12: F#4 延长（V级三音）

      % === 第四乐句 ===
      g2 b4 g4 |               % 13: G4-B4-G4，I级根音+三音
      e2 c2 |                  % 14: E4-C4，IV级三音→根音（两个二分音符）
      d2 fis4 a4 |             % 15: D4-F#4-A4，V级完整三和弦展开
      b2.\fermata r4 |          % 16: B4 延长（I级三音，PAC）
    }

    % ═══════════════════════════════════════════════════
    % 男高音 Tenor — 内声部（附点节奏 + 休止）
    % 特征：附点四分 + 八分音符 + 休止符，节奏与 S/A 完全不同
    % ═══════════════════════════════════════════════════
    \new Staff \relative c' {
      \clef "treble_8"
      \key g \major
      \time 4/4

      % === 第一乐句 ===
      % Tenor 的典型模式：附点节奏后接休止，制造"问答"感
      g4. fis8 g4 r4 |         % 1: G3-F#3-G3-休止，I级根音，附点+休止
      g4. a8 g4 r4 |           % 2: G3-A3-G3-休止，IV级经过音
      a4. g8 fis4 d4 |         % 3: A3-G3-F#3-D3，V级下行到低音区
      d2.\fermata r4 |          % 4: D3 延长（I级五音）

      % === 第二乐句 ===
      g4. a8 b4 r4 |           % 5: G3-A3-B3-休止，I级上行
      b4. a8 g4 fis4 |         % 6: B3-A3-G3-F#3，vi级下行（无休止，变化）
      g4. a8 g4 r4 |           % 7: G3-A3-G3-休止，IV级
      d2.\fermata r4 |          % 8: D3 延长（V级根音，半终止）

      % === 第三乐句 ===
      g4. a8 b4 r4 |           % 9: G3-A3-B3-休止，I级
      g4. fis8 e4 r4 |         % 10: G3-F#3-E3-休止，下行
      fis4. g8 a4 r4 |         % 11: F#3-G3-A3-休止，V级准备上行
      d2.\fermata r4 |          % 12: D3 延长（V级根音）

      % === 第四乐句 ===
      g4. b8 g4 r4 |           % 13: G3-B3-G3-休止，I级根音→三音跳进
      g4. fis8 e4 r4 |         % 14: G3-F#3-E3-休止，IV级下行
      d4. cis8 a4 r4 |         % 15: D3-C#3-A3-休止，V级根音→导音→五音
      d2.\fermata r4 |          % 16: D4 延长（I级五音，PAC）
    }

    % ═══════════════════════════════════════════════════
    % 男低音 Bass — 和声基础（最稳定）
    % 特征：二分音符为主，提供根音/五音支撑
    % ═══════════════════════════════════════════════════
    \new Staff \relative c {
      \clef bass
      \key g \major
      \time 4/4

      % === 第一乐句 ===
      % Bass 用根音-五音的二分音符模式奠定基础
      g2 d'2 |                 % 1: G2-D3（I: 根音→五音）
      c2 e2 |                  % 2: C3-E3（IV: 根音→三音）
      d2 a2 |                  % 3: D3-A2（V: 根音→五音）
      g2.\fermata r4 |          % 4: G2 延长（I: 根音）

      % === 第二乐句 ===
      g2 d'2 |                 % 5: G2-D3（I: 根音→五音）
      e2 b2 |                  % 6: E3-B2（vi: 根音→五音）
      c2 e2 |                  % 7: C3-E3（IV: 根音→三音）
      d2.\fermata r4 |          % 8: D3 延长（V: 根音，半终止）

      % === 第三乐句 ===
      e2 b2 |                  % 9: E3-B2（vi: 根音→五音）
      c2 a2 |                  % 10: C3-A2（IV/ii 区域）
      g2 d'2 |                 % 11: G2-D3（I: 根音→五音）
      d2.\fermata r4 |          % 12: D3 延长（V: 根音）

      % === 第四乐句 ===
      g,2 d'2 |                % 13: G2-D3（I: 根音→五音，从 D3 跳回 G2）
      c2 e2 |                  % 14: C3-E3（IV: 根音→三音）
      d2 a2 |                  % 15: D3-A2（V: 根音→五音）
      g2.\fermata r4 |          % 16: G2 延长（I: 根音，PAC 基础）
    }

  >>
  \layout {
    indent = 0
  }
}
```

## 三、节奏独立性分析

上面示例中，四个声部在同一小节内呈现**截然不同的节奏型**：

### 第 1 小节节奏对比

```
Soprano:  ♩  ♪♩♪  ♩  ♩          （四分+八分混合，4个节奏单元）
Alto:     ♩.        ♩            （附点二分+四分，2个节奏单元）
Tenor:    ♩.  ♪  ♩  𝄽           （附点四分+八分+四分+休止，含休止符）
Bass:     𝅗𝅥    𝅗𝅥               （两个二分音符，最简节奏）
```

四个声部的节奏型**完全不同**——这是圣咏写作的核心要求。

### 第 3 小节节奏对比（更有变化的小节）

```
Soprano:  ♩  ♪♪  ♩  ♩          （八分音符组出现在中间）
Alto:     𝅝                     （全音符！一个音持续整小节）
Tenor:    ♩.  ♪  ♩  ♩          （附点开头，两个四分结尾）
Bass:     𝅗𝅥    𝅗𝅥               （二分音符，与 Alto 的全音符互补）
```

注意 Alto 的全音符与 Soprano/Tenor 的活跃节奏形成**长-短互补**。

## 四、和声与声部进行检查

### 终止分析

| 小节 | 终止类型 | Soprano 结束音 | 条件 |
|------|---------|--------------|------|
| 4 | IAC | G4（主音） | V→I，但低音非主音位置 |
| 8 | HC | A4（V的五音） | 停在 V 和弦 |
| 12 | HC | A4（V的五音） | 停在 V 和弦 |
| 16 | **PAC** | G5（主音） | V→I 均原位，高音=主音 |

### 最终和弦（第 16 小节）

| 声部 | 音符 | 和弦功能 |
|------|------|---------|
| Soprano | G5 | 根音（主音） |
| Alto | B4 | 三音 |
| Tenor | D4 | 五音 |
| Bass | G2 | 根音 |

G2–D4–B4–G5 = **完整的 G 大三和弦**，根音重复。PAC 条件满足 ✓

### 声部间距检查（抽查第 14 小节）

- S–A：E5–E4 = 八度 ≤ 八度 ✓
- A–T：E4–G3 = 大六度 ≤ 八度 ✓
- T–B：G3–C3 = 纯五度（无限制）✓
- 无声部交错 ✓、无声部超越 ✓

## 五、写作要点总结

1. **节奏互补原则**：Soprano 活跃时 Alto/Tenor 用长音；Bass 始终最稳定
2. **fermata 统一**：乐句结尾所有声部同时延长，这是圣咏的标志性特征
3. **导音处理**：V 级中的导音（如 cis = C#）必须上行解决到主音（d = D）
4. **共同音保持**：和弦切换时，共同音尽量在同一声部保持（如 Alto 的 b 在 I-vi 之间保持）
5. **Bass 的根音-五音模式**：每小节两个二分音符，先根音后五音（或根音-三音），提供清晰的和声节奏
6. **力度克制**：全曲 mp–mf，仅在第三乐句稍微加强（\mf），最后乐句用渐强（\<）推向终止
