# 进行曲织体 (March Texture)

进行曲的核心织体特征是附点节奏"哒-嘀-哒"（dah-dit-dah）动机、强拍重音、以及号角式的三和弦分解旋律。音域与乐器规范 → 见 shared-rules.md。

## 织体特征

| 特征 | 说明 |
|------|------|
| 拍号 | 2/4 或 4/4（本示例使用 4/4） |
| 速度 | Marcia, 4 = 110-130（军队进行曲偏快，婚礼进行曲偏慢） |
| 左手/低音模式 | 低音-和弦交替：拍点 1/3 = 低音（根音-五音），拍点 2/4 = 柱式和弦 |
| 右手/旋律模式 | 号角式旋律：附点四分+八分音符为主，大量重音 (->)，三和弦分解进行 |
| 声部关系 | 左手拆分为两个声部：低音声部（符干朝下）+ 和弦声部（符干朝上） |
| 力度范围 | f - ff，sfz 重音；极少出现 p（仅在对比段落） |
| 和声节奏 | 每小节一个和弦，终止处可能延长至两小节 |

## LilyPond 核心模式

### 右手附点节奏模式

进行曲最具辨识度的特征——"哒-嘀-哒"附点动机：

```lilypond
% 进行曲核心节奏：附点四分+八分音符
\relative c'' {
  \clef treble
  \time 4/4
  \key bes \major
  % 号角式动机：同一节奏型重复，配合三和弦分解
  bes4.-> bes8 d4.-> d8 |      % 附点节奏 ×2，重音在拍点
  f4.-> f8 d4 bes4 |            % 上行到 F5 后回落
  f4.-> f8 f4 ees4 |            % 持续高音 + 半音下行
  d2.-> bes4 |                  % 长音收束
}
```

**节奏型速查：**

| 模式 | LilyPond | 说明 |
|------|---------|------|
| 标准附点 | `c4.-> c8` | "哒-嘀"：最基本的进行曲动机 |
| 双附点 | `c4.-> c8 d4.-> d8` | 连续两组，形成 1 小节完整动机 |
| 长音收束 | `c2.-> c4` | 前 3 拍长音 + 第 4 拍短音 |
| 级进下行 | `c4-> bes4-> a4-> g4->` | 四个四分音符，用于对比段落 |

### 左手"低音-和弦"伴奏模式

与圆舞曲类似，使用 `<< \\ >>` 双声部写法。区别在于：进行曲是 4 拍交替（拍点 1/3 = 低音，拍点 2/4 = 和弦），而非圆舞曲的 3 拍。

```lilypond
% 左手进行曲核心模式（降B大调 Bb 和弦）
\new Staff {
  \clef bass
  \time 4/4
  \key bes \major
  <<
    { % Voice 1：和弦（第二、四拍），符干朝上
      % Bb = <Bb3 D4 F4>，记作 <bes d' f'>
      s4 <bes d' f'>4 s4 <bes d' f'>4 |
    }
    \\
    \relative c { % Voice 2：低音（第一、三拍），符干朝下
      % 根音-五音交替：bes(Bb2) - f(F2) - bes - f
      bes4 f bes f |
    }
  >>
}
```

**常用和弦的绝对音高写法速查：**

| 和弦 | LilyPond 写法 | 实际音高 |
|------|--------------|---------|
| Bb | `<bes d' f'>4` | Bb3-D4-F4 |
| Eb | `<ees g bes>4` | Eb3-G3-Bb3 |
| F  | `<f a c'>4` | F3-A3-C4 |
| Cm | `<c ees g>4` | C3-Eb3-G3 |

## 完整示例（16 小节）

```lilypond
\version "2.24.0"
\header {
  title = "降B大调进行曲"
  composer = "仿苏萨风格"
}

\score {
  \new PianoStaff <<

    % ================================================
    % 右手（RH）：号角式旋律声部
    % 特征：附点节奏主导、强拍重音、三和弦分解上行
    % \relative c'' → 起始参考音 C5（钢琴右手标准）
    % ================================================
    \new Staff = "RH" \relative c'' {
      \clef treble
      \time 4/4
      \key bes \major
      \tempo "Marcia" 4 = 120

      % ── 第一乐句（第1-4小节）：主题呈示 ──
      % 号角式开头：附点动机 + Bb 大三和弦分解 (Bb4→D5→F5)

      \f
      bes4.-> bes8 d4.-> d8          % 1: Bb — 双附点动机，号角齐鸣
      | f4.-> f8 d4 bes4              % 2: Bb — 三和弦分解上行 Bb→D→F，再回落
      | ees4.-> ees8 c4.-> c8         % 3: Eb — 转向下属方向 (Eb5→C5)
      | d2.-> bes4                    % 4: Bb — 长音回到主音 D5→Bb4

      % ── 第二乐句（第5-8小节）：发展 ──
      % 旋律通过 D5 跳进到 F5，到达更高的音区

      | bes4.-> d8 f4.-> f8           % 5: Bb — 通过 D5 跳进到 F5
      | d4.-> bes8 a4 a4              % 6: F — 回落，经过 A4（F 和弦的三音）
      | bes4.-> d8 f4.-> f8           % 7: Bb — 重复上行动机，加强力度
      | f2.-> d4                      % 8: F — 停留在高音 F5→D5

      % ── 第三乐句（第9-12小节）：对比段 ──
      % 节奏变为四分音符级进，与前面的附点节奏形成对比
      % 力度降至 mf，为最后的再现积蓄能量

      \mf
      | f4-> ees4-> d4-> c4->         % 9: Eb — 级进下行（每拍一个重音）
      | bes4.-> bes8 g4.-> g8         % 10: Bb — 附点回归，跳进下行到 G4
      | ees'4.-> ees8 d4-> c4->       % 11: Eb — 回到高音区 Eb5，混合节奏
      | d2.-> bes4                    % 12: Bb — 半终止，回到 Bb4

      % ── 第四乐句（第13-16小节）：结尾 ──
      % 力度回到 f，主题动机再现，强有力地终止

      \f
      | bes4.-> d8 f4.-> f8           % 13: Bb — 回归号角动机
      | f4.-> f8 ees4-> d4->          % 14: Eb — 下行进行 (F5→Eb5→D5)
      | ees4.-> d8 c4-> bes4->        % 15: F→Bb — 终止式 (Eb5→D5→C5→Bb4)
      | bes1-> \fermata \bar "|."     % 16: Bb — 全音符终止 + 延长记号
    }

    % ================================================
    % 左手（LH）：低音+和弦交替伴奏
    % 双声部结构：
    %   Voice 1（符干朝上）= 和弦，第2/4拍，绝对音高
    %   Voice 2（符干朝下）= 低音，第1/3拍，\relative c
    % ================================================
    \new Staff = "LH" {
      \clef bass
      \time 4/4
      \key bes \major
      <<
        % ── 和弦声部（Voice 1，绝对音高） ──
        % s4 占位低音拍，和弦填充第 2/4 拍
        % Bb = <Bb3 D4 F4>, Eb = <Eb3 G3 Bb3>, F = <F3 A3 C4>
        {
          % 第一乐句 (1-4): Bb Bb Eb Bb
          s4 <bes d' f'>4 s4 <bes d' f'>4        % 1: Bb
          | s4 <bes d' f'>4 s4 <bes d' f'>4      % 2: Bb
          | s4 <ees g bes>4 s4 <ees g bes>4      % 3: Eb
          | s4 <bes d' f'>4 s4 <bes d' f'>4      % 4: Bb

          % 第二乐句 (5-8): Bb F Bb F
          | s4 <bes d' f'>4 s4 <bes d' f'>4      % 5: Bb
          | s4 <f a c'>4 s4 <f a c'>4            % 6: F
          | s4 <bes d' f'>4 s4 <bes d' f'>4      % 7: Bb
          | s4 <f a c'>4 s4 <f a c'>4            % 8: F

          % 第三乐句 (9-12): Eb Bb F F
          | s4 <ees g bes>4 s4 <ees g bes>4      % 9: Eb
          | s4 <bes d' f'>4 s4 <bes d' f'>4      % 10: Bb
          | s4 <f a c'>4 s4 <f a c'>4            % 11: F
          | s4 <f a c'>4 s4 <f a c'>4            % 12: F

          % 第四乐句 (13-16): Bb Eb F Bb
          | s4 <bes d' f'>4 s4 <bes d' f'>4      % 13: Bb
          | s4 <ees g bes>4 s4 <ees g bes>4      % 14: Eb
          | s4 <f a c'>4 s4 <f a c'>4            % 15: F
          | <bes d' f'>1                          % 16: Bb — 全音符终止和弦
        }
        \\
        % ── 低音声部（Voice 2，\relative c，参考音 C3） ──
        % 每小节：根音(拍1) - 五音(拍3) 交替
        % 八度标记要点：
        %   bes = Bb2（从 C3 下行大二度）
        %   f = F2（从 Bb2 下行纯四度）
        %   ees, = Eb2（从 Bb2 下行三全音，需逗号）
        %   c' = C3（从 F2 上行纯五度，需撇号）
        \relative c {
          % 第一乐句 (1-4): Bb Bb Eb Bb
          bes4 f bes f                             % 1: Bb2-F2-Bb2-F2
          | bes4 f bes f                           % 2: 同上
          | ees4 bes' ees, bes'                    % 3: Eb2-Bb2-Eb2-Bb2（注意 ees, 和 bes'）
          | bes4 f bes f                           % 4: Bb2-F2-Bb2-F2

          % 第二乐句 (5-8): Bb F Bb F
          | bes4 f bes f                           % 5: Bb
          | f4 c' f c'                             % 6: F2-C3-F2-C3（注意 c' 标记）
          | bes4 f bes f                           % 7: Bb
          | f4 c' f c'                             % 8: F

          % 第三乐句 (9-12): Eb Bb F F
          | ees4 bes' ees, bes'                    % 9: Eb
          | bes4 f bes f                           % 10: Bb
          | f4 c' f c'                             % 11: F
          | f4 c' f c'                             % 12: F

          % 第四乐句 (13-16): Bb Eb F Bb
          | bes4 f bes f                           % 13: Bb
          | ees4 bes' ees, bes'                    % 14: Eb
          | f4 c' f c'                             % 15: F
          | bes2 r2                                % 16: Bb2 二分音符 + 休止
        }
      >>
    }
  >>
  \layout { }
}
```

## 低音声部八度标记详解

进行曲低音声部在 `\relative c`（C3 参考）中，有三个需要特别注意的八度标记：

| 写法 | 含义 | 何时使用 | 记忆口诀 |
|------|------|---------|---------|
| `bes` | Bb2（无标记） | 紧跟 C3 或 F2 之后 | 从 C3 下行大二度，自然到达 |
| `ees,` | Eb2（加逗号） | 紧跟 Bb2 之后 | Bb 到 Eb 是三全音（6 半音），需逗号拉低 |
| `bes'` | Bb2（加撇号） | 紧跟 Eb2 之后 | Eb 到 Bb 是纯五度（超 4 度），需撇号拉高 |
| `c'` | C3（加撇号） | 紧跟 F2 之后 | F 到 C 是纯五度（超 4 度），需撇号拉高 |
| `f` | F2（无标记） | 紧跟 Bb2 之后 | Bb 到 F 是纯四度（5 半音），自然到达 |

**核心原则**：LilyPond `\relative` 模式下，纯四度以内的进行（≤5 半音）自动保持正确八度；超过纯四度的跳进需要显式标记 `'` 或 `,`。

## 写作要点

1. **附点节奏是灵魂**：进行曲的辨识度来自 `4. 8` 附点节奏。至少 60% 的旋律小节应包含附点动机。避免过多使用均匀的四分音符（仅在对比段落使用）。
2. **重音标记不可省略**：每个重要拍点都应加 `->` (accent)。进行曲的重音是"进行感"的来源。终止处可用 `\fermata` 延长。
3. **三和弦分解进行**：旋律应大量使用主三和弦的分解音（如 Bb-D-F），形成号角般的音响效果。避免过多级进（级进留给对比段落）。
4. **左手双声部**：同圆舞曲，使用 `<< \\ >>` 分离低音和和弦。低音用根音-五音交替（`bes4 f bes f`），和弦用绝对音高。
5. **力度对比**：主旋律段 f，对比段 mf，结尾可加 ff 或 sfz。不要全曲同一力度。
6. **4 小节乐句**：进行曲的乐句结构非常规整，严格 4+4 或 4+4+4+4。不要写出不规则的乐句长度。

## 变体

- **葬礼进行曲**（Funeral March）：小调（如 Bb 小调），速度更慢（4 = 60-72），附点节奏更沉重（可加 `--` 保持音代替 `->` 重音），低音使用八度进行而非根音-五音交替。参考肖邦《葬礼进行曲》。
- **婚礼进行曲**（Wedding March）：速度中慢（4 = 72-84），使用更丰满的四音和弦，旋律更加庄严。参考门德尔松/瓦格纳婚礼进行曲。
- **军队进行曲**（Military March）：速度更快（4 = 130-140），增加铜管式号角音型 `\times 2/3 { c8 c c }` 三连音，更多 sfz 和 ff 力度。参考苏萨《星条旗永不落》。
- **2/4 拍进行曲**：将本示例的 4/4 压缩为 2/4，每小节只有"低音-和弦"一对（`bes4 <bes' d' f'>4`），节奏更紧凑，适合短小的进行曲片段。
