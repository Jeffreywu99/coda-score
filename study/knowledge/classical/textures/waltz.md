# 圆舞曲织体 (Waltz Texture)

圆舞曲（华尔兹）的核心织体特征是左手"低音-和弦-和弦"（嘣-嚓-嚓）三拍子伴奏模式，配合右手抒情性旋律。音域与乐器规范 → 见 shared-rules.md。

## 织体特征

| 特征 | 说明 |
|------|------|
| 拍号 | 3/4（每小节三拍） |
| 速度 | Tempo di Valse, 4 = 120-168（肖邦风格偏慢 ~144） |
| 左手/低音模式 | 第一拍：低八度根音（二分附点）；第二三拍：中音区柱式和弦 |
| 右手/旋律模式 | 抒情歌唱性旋律，大量附点节奏（4. 8），连句跨越 4 小节 |
| 声部关系 | 左手拆分为两个声部：低音声部（符干朝下）+ 和弦声部（符干朝上） |
| 力度范围 | pp - f，以 p 和 mp 为主，B 段高潮可达 f |
| 和声节奏 | 每小节一个和弦（偶尔两小节一个和弦） |

## LilyPond 核心模式

### 左手"嘣嚓嚓"伴奏模式

左手使用 `<< \\ >>` 双声部写法：**Voice 1**（和弦，绝对音高）+ **Voice 2**（低音，`\relative c`）。

```lilypond
% 左手华尔兹核心模式（A小调 Am 和弦）
% 和弦声部使用绝对音高，避免 \relative 模式中大跳导致的八度混乱
\new Staff {
  \clef bass
  \time 3/4
  <<
    { % Voice 1：和弦（第二、三拍），符干朝上
      % Am = <E4 A4 C5>，记作 <e' a' c''>
      s4 <e' a' c''>4 <e' a' c''>4 |
    }
    \\
    \relative c { % Voice 2：低音（第一拍根音），符干朝下
      % a, 从 C3 下行到 A2（低八度根音）
      a,2. |
    }
  >>
}
```

**常用和弦的绝对音高写法速查：**

| 和弦 | LilyPond 写法 | 实际音高 |
|------|--------------|---------|
| Am | `<e' a' c''>4` | E4-A4-C5 |
| Dm | `<a d' f'>4` | A3-D4-F4 |
| E  | `<b e' gis'>4` | B3-E4-G#4 |
| F  | `<c' f' a'>4` | C4-F4-A4 |
| C  | `<g c' e'>4` | G3-C4-E4 |

### 右手抒情旋律模式

```lilypond
% 右手附点旋律核心模式（A小调）
\relative c'' {
  \clef treble
  \time 3/4
  % 附点四分+八分音符：华尔兹最典型的歌唱性节奏
  % 连音线跨越整个 4 小节乐句
  a4.(\p b8 c4 |        % 上行，柔和起句
  d2 c4 |                % 到达高点后回落
  b4 a gis |             % 级进下行，经过导音
  a2) r4 |               % 解决到主音，乐句收束
}
```

## 完整示例（20 小节）

```lilypond
\version "2.24.0"
\header {
  title = "A小调圆舞曲"
  composer = "仿肖邦风格"
}

\score {
  \new PianoStaff <<

    % ================================================
    % 右手（RH）：抒情旋律声部
    % 特征：附点节奏、4小节连句、渐进式力度起伏
    % \relative c'' → 起始参考音 C5（钢琴右手标准）
    % ================================================
    \new Staff = "RH" \relative c'' {
      \clef treble
      \time 3/4
      \key a \minor
      \tempo "Tempo di Valse" 4 = 144

      % ── A段（第1-8小节）：主题呈示 ──

      % 第1-4小节：第一乐句（Am → Dm → E）
      % 旋律从 A4 柔和上行，附点节奏营造歌唱感
      \p
      a4.(\p b8 c4            % 1: Am — 附点上行动机 (A4→B4→C5)
      d2 c4                    % 2: Am — 到达 D5 后回落
      b4 a g                   % 3: Dm — 级进下行 (B4→A4→G4)
      gis2) r4                 % 4: E  — 导音 G#4 长音，半终止

      % 第5-8小节：第二乐句（Am → Dm → E），音区升高
      a4.( b8 c4               % 5: Am — 重复动机
      d4 e f                   % 6: Am — 旋律上行至高音区 (D5→E5→F5)
      e4. d8 c4                % 7: Dm — 从高点回落
      b2) r4                   % 8: E  — 半终止

      % ── B段（第9-12小节）：对比中段 ──
      % 转到关系大调区域，力度增强，旋律到达全曲最高音区

      \mf
      c4.(\mf d8 e4            % 9:  F — 新段落，从 C5 上行
      f2 e4                    % 10: C — 到达 F5（全曲高点）
      d4. c8 b4                % 11: Dm — 渐弱回落
      c2) r4                   % 12: E — 为再现做准备

      % ── A'段（第13-16小节）：再现 ──
      % 主题回归，力度减弱，带有回忆般的色彩

      \p
      a4.(\p b8 c4             % 13: Am — 主题回归
      d4. e8 f4                % 14: Dm — 旋律再次攀升
      a,4. g8 f4               % 15: Dm — 大幅回落（注意 a, 八度标记：从 F5 降至 A4）
      e2) r4                   % 16: E — 属准备

      % ── 尾声（第17-20小节） ──
      % 力度渐弱至 pp，渐慢（rit.），最终完满终止

      a4.( b8 c4               % 17: Am — 尾声动机
      d4. c8 b4                % 18: Dm — 下行
      a4. gis8 a4              % 19: E → Am — 导音到主音
      a2.)\pp \bar "|."        % 20: Am — 完满正格终止 (PAC)
    }

    % ================================================
    % 左手（LH）：华尔兹"嘣嚓嚓"伴奏
    % 双声部结构：
    %   Voice 1（符干朝上）= 和弦，第二三拍，绝对音高
    %   Voice 2（符干朝下）= 低音，第一拍，\relative c
    % ================================================
    \new Staff = "LH" {
      \clef bass
      \time 3/4
      \key a \minor
      <<
        % ── 和弦声部（Voice 1，绝对音高） ──
        % s4 占位第一拍，和弦填充第二三拍
        {
          % A段 (1-8)
          s4 <e' a' c''>4 <e' a' c''>4       % 1: Am
          | s4 <e' a' c''>4 <e' a' c''>4     % 2: Am
          | s4 <a d' f'>4 <a d' f'>4          % 3: Dm
          | s4 <b e' gis'>4 <b e' gis'>4      % 4: E
          | s4 <e' a' c''>4 <e' a' c''>4     % 5: Am
          | s4 <e' a' c''>4 <e' a' c''>4     % 6: Am
          | s4 <a d' f'>4 <a d' f'>4          % 7: Dm
          | s4 <b e' gis'>4 <b e' gis'>4      % 8: E

          % B段 (9-12)
          | s4 <c' f' a'>4 <c' f' a'>4        % 9:  F
          | s4 <g c' e'>4 <g c' e'>4          % 10: C
          | s4 <a d' f'>4 <a d' f'>4          % 11: Dm
          | s4 <b e' gis'>4 <b e' gis'>4      % 12: E

          % A'段 (13-16)
          | s4 <e' a' c''>4 <e' a' c''>4     % 13: Am
          | s4 <a d' f'>4 <a d' f'>4          % 14: Dm
          | s4 <a d' f'>4 <a d' f'>4          % 15: Dm
          | s4 <b e' gis'>4 <b e' gis'>4      % 16: E

          % 尾声 (17-20)
          | s4 <e' a' c''>4 <e' a' c''>4     % 17: Am
          | s4 <a d' f'>4 <a d' f'>4          % 18: Dm
          | s4 <b e' gis'>4 <b e' gis'>4      % 19: E
          | s4 <e' a' c''>4 <e' a' c''>4     % 20: Am
        }
        \\
        % ── 低音声部（Voice 2，\relative c，参考音 C3） ──
        % 每小节一个二分附点音符，占据整小节
        % 和声规则：根音为主，偶尔使用五音
        \relative c {
          % A段 (1-8)
          a,2. | a2. | d,2. | e2. |           % Am Am Dm E (A2 A2 D2 E2)
          a2.  | a2. | d,2. | e2. |           % Am Am Dm E

          % B段 (9-12)
          f2. | c2. | d2. | e2. |             % F C Dm E (F2 C2 D2 E2)

          % A'段 (13-16)
          a2. | d,2. | d2. | e2. |            % Am Dm Dm E

          % 尾声 (17-20)
          a2. | d,2. | e2. | a2. |            % Am Dm E Am
        }
      >>
    }
  >>
  \layout { }
}
```

## 写作要点

1. **左手必须用双声部**：低音和和弦是独立的节奏层。低音用二分附点（持续整小节），和弦用两个四分音符（占第二三拍）。不要写成单声部的 `a,4 <e' a' c'>4 <e a c'>4`——大跳会导致 `\relative` 八度混乱。
2. **和弦声部用绝对音高**：因为和弦在每小节重复，`\relative` 模式下第二个和弦会因为参考音变化而跑到错误八度。绝对音高（如 `<e' a' c''>4`）保证每次一致。
3. **低音声部的八度标记**：在 `\relative c`（C3 参考）中，`a,` = A2，`d,` = D2。连续两小节同音时，第二小节的 `a` 不需要逗号（因为参考音已经是 A2）。
4. **右手旋律的连句**：用 `(` 和 `)` 标记 4 小节乐句，不要在每小节断开。休止符 `r4` 在连句结束后使用。
5. **力度布局**：A 段 p，B 段 mf，再现 p，尾声 pp。避免全曲同一力度。

## 变体

- **维也纳华尔兹**：速度更快（4 = 180+），左手和弦更轻（可加 `-.` 跳音标记），旋律更华丽，多用装饰音 `\grace { b16 } c4`。
- **慢华尔兹**：速度更慢（4 = 84-100），左手改为分解和弦 `a,4 e'4 c'4`（类似吉他拨弦），旋律更加悠长。
- **肖邦式自由低音**：左手不再严格"低音-和弦-和弦"，而是使用琶音 `a,8 e' c' e' a' c''`，营造更丰富的音响。适用于抒情段落。
- **带对位的华尔兹**：在右手旋律下方添加一个对旋律声部（用 `<< \\ >>` 在 RH 谱表上写两个声部），增加织体厚度。
